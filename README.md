# License Lens · 复核会台

在原许可证扫描面板之上扩展的「复核会议」工作台：法务和开发逐项确认依赖，
主持人冻结快照并导出。

## 复核流程

1. **逐项指派**：每个待复核依赖（扫描状态为 warn / risk）指派一名复核人和计划完成时间。
2. **意见绑定快照**：提交意见（可接受 / 附条件通过 / 需替换 + 批注）时，
   自动绑定当时的 **版本、许可证、风险状态**。
3. **重新扫描 → 自动待重审**：重新扫描后包信息（版本 / 许可证 / 风险状态）变化时，
   旧意见自动转为「待重审」，差异逐字段提示；重审确认后旧意见进入历史，批注永久保留。
4. **冻结并导出**：所有待复核 / 待重审项确认完毕后，主持人才能冻结会议快照并导出
   Markdown 报告；冻结后会议只读。
5. **另开新会议**：冻结后的重新扫描与意见改动进入新的复核会议（编号递增，
   旧会议归档只读，新会议沿用最新包信息与复核人指派，意见重新走流程）。

## 分层结构（数据 / 判断 / 保存 / 页面分开）

| 层 | 目录 | 职责 | 不允许接触 |
|---|---|---|---|
| 数据 | `src/types.ts`、`src/data/` | 领域模型、人员、初始扫描与重扫模拟场景 | 逻辑、React、存储 |
| 判断 | `src/domain/meeting.ts`、`src/domain/report.ts` | 纯函数：复核状态判定、快照差异、指派/提交/重扫/冻结/另开会议、报告生成 | React、localStorage、DOM |
| 保存 | `src/storage/meetingStore.ts` | 版本化 localStorage 读写、文件下载 | 业务判断、React |
| 桥接 | `src/state/useReviewMeeting.ts` | 把领域纯函数接到 React 状态，自动持久化 | JSX |
| 页面 | `src/components/`、`src/App.tsx` | 展示与交互 | 直接读写存储、跨层判断 |

关键派生状态（待复核 / 已确认 / 待重审 / 无需复核）由领域层根据
「意见绑定快照 vs 当前扫描」实时计算，不单独存储，避免状态不一致。

## 脚本

- `npm run dev` 本地开发
- `npm run build` 类型检查 + 生产构建
- `npm run verify` 运行领域逻辑验证（26 项断言，覆盖指派、绑定、重审、冻结、归档）
